# Vision

## محصول

نام موقت: **HSE Management Platform**

سامانهٔ سازمانی برای مدیریت یکپارچهٔ بهداشت، ایمنی (پیشگیری)، بیمه، و محیط زیست در سازمان‌هایی که عملیات صنعتی، پروژه‌ای یا چندسایتی دارند.

## ارزش

- کاهش حوادث و ریسک با ثبت و پیگیری سیستمی
- انطباق با الزامات قانونی و بیمه‌ای
- پروندهٔ سلامت شغلی قابل‌حسابرسی بدون افشای بی‌مورد PHI
- دید مدیریتی از KPIهای HSE
- مسیر توسعهٔ ماژول‌های بعدی (آموزش، پیمانکار، تجهیزات، اسناد، CAPA گسترده)

## اصول محصول

1. **ایمنی داده مقدم است.** اطلاعات پزشکی و شخصی Sensitive Data هستند.
2. **دسترسی بر اساس Permission است، نه صرفاً نقش ثابت.** منو و داده هر دو فیلتر می‌شوند.
3. **فرآیند قابل‌پیکربندی است.** Stateهای Workflow هاردکد نیستند.
4. **سازمان قابل‌پیکربندی است.** سلسله‌مراتب شش‌سطحی ثابت نیست.
5. **ماژول جدید نباید هسته را بشکند.**
6. **گزارش write-model را آلوده نمی‌کند.**
7. **ساده بمان تا وقتی پیچیدگی اجباری شود.**

## کاربران اولیه (فرض)

- کارشناس / مسئول HSE
- پزشک طب کار / کارشناس بهداشت حرفه‌ای
- سرپرست واحد
- کارشناس بیمه
- کارشناس محیط زیست
- مدیر HSE (داشبورد و تأیید)
- راهبر سیستم (Administration)

نقش‌های دقیق در Identity پیکربندی می‌شوند؛ این فهرست فقط برای طراحی اولیه است.
