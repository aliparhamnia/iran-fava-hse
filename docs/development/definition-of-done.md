# Definition of Done

هیچ Featureای کامل نیست مگر:

- Domain طراحی شده باشد
- Business Rules مشخص باشند
- Database Migration انجام شده باشد
- Application Logic پیاده شده باشد
- Authorization انجام شده باشد
- Validation انجام شده باشد
- UI ساخته شده باشد
- Error Handling انجام شده باشد
- Audit در صورت نیاز اضافه شده باشد
- Logging مناسب وجود داشته باشد
- Unit Test برای قوانین مهم نوشته شده باشد
- Integration Test در صورت نیاز نوشته شده باشد
- Documentation به‌روز شده باشد

اگر یکی نباشد، Feature باز است نه «تقریباً تمام».
